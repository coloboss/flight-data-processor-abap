# Flight Data Processor (ABAP)

## Project Overview

This project demonstrates basic ABAP programming concepts using internal tables.  
The dataset is based on the SAP standard structure SPFLI (flight connections).

The goal was to practice core ABAP skills such as filtering, searching, and working with internal tables.

---

## Features

- Internal table creation using `VALUE #( )`
- Data filtering using `LOOP` and `IF`
- Record search using `READ TABLE`
- Handling return code with `sy-subrc`
- Creating a filtered VIP list
- Checking table content using `LINES( )`
- Modern ABAP syntax:
  - `FILTER #( )`
  - `REDUCE #( )`
